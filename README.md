\# GasApp Data 📊



\## Descripción del proyecto



\*\*GasApp Data\*\* es un proyecto integrador orientado al registro, la limpieza y el análisis de datos relacionados con el peso y el monitoreo de un sistema de medición de gas.



El proyecto combina programación, procesamiento de datos y pruebas de software para evaluar el funcionamiento del sistema y la calidad de la información obtenida.



\## 🎯 Objetivos



\- Registrar y organizar los datos recopilados por el sistema.

\- Limpiar y transformar los datos para facilitar su análisis.

\- Detectar valores inválidos o inconsistentes.

\- Realizar un análisis exploratorio de datos (EDA).

\- Verificar el funcionamiento del sistema mediante pruebas de software.

\- Generar información útil para la toma de decisiones.



\## 🛠️ Tecnologías utilizadas



\- \*\*Python:\*\* programación y procesamiento de datos.

\- \*\*Pandas:\*\* limpieza y organización de datos.

\- \*\*NumPy:\*\* operaciones y cálculos.

\- \*\*Matplotlib:\*\* visualización de datos.

\- \*\*Jupyter Notebook / Google Colab:\*\* desarrollo y documentación de análisis.

\- \*\*Git y GitHub:\*\* control de versiones y almacenamiento del proyecto.



\## 📁 Estructura del repositorio



\- `Agent.py`: archivo de código Python del proyecto.

\- `GasApp\_Datos\_Limpios.csv`: conjunto de datos procesados.

\- `Testeo de sofware y P.P..ipynb`: notebook de trabajo relacionado con testeo y práctica profesionalizante.

\- `requirements.txt`: dependencias necesarias para ejecutar el proyecto.

\- `.gitignore`: archivos y carpetas excluidos del repositorio.



\## 🧪 Testeo de software



El proyecto contempla pruebas para verificar el funcionamiento del sistema, la lectura y el almacenamiento de datos, el comportamiento ante problemas de conexión y la detección de valores inválidos.



\## 📈 Análisis de datos



El trabajo incluye actividades de análisis exploratorio de datos (EDA), limpieza, transformación y preparación de la información para su posterior interpretación y visualización.



\## ▶️ Instalación y ejecución



1\. Clonar el repositorio:



&#x20;  ```bash

&#x20;  git clone https://github.com/Januley/Gasapp-data.git

&#x20;  ```



2\. Ingresar a la carpeta:



&#x20;  ```bash

&#x20;  cd Gasapp-data

&#x20;  ```



3\. Crear un entorno virtual:



&#x20;  ```bash

&#x20;  python -m venv .venv

&#x20;  ```



4\. Activar el entorno virtual en Windows:



&#x20;  ```bash

&#x20;  .venv\\Scripts\\activate

&#x20;  ```



5\. Instalar las dependencias:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



6\. Ejecutar el programa:



&#x20;  ```bash

&#x20;  python Agent.py

&#x20;  ```



&#x20;  Para abrir el notebook, se puede utilizar Jupyter Notebook o Google Colab.
